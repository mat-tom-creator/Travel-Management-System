# Travel Management System

A Java-based travel management system built with Java Applet and MySQL database. This desktop application provides a comprehensive solution for managing travel bookings, customer information, and travel packages for travel agencies.

## 🌟 Features

### Customer Management
- **Customer Registration** - Add new customers to the system
- **Customer Login** - Secure customer authentication
- **Update Customer Details** - Modify customer information
- **View Customer Information** - Display customer profiles
- **Delete Customer Records** - Remove customer data

### Travel Package Management
- **Browse Packages** - View available travel packages
- **Package Details** - Detailed information about destinations
- **Book Packages** - Reserve travel packages for customers

### Hotel Management
- **Hotel Booking** - Reserve hotel accommodations
- **Check Hotel Availability** - View available hotels
- **Hotel Information** - Display hotel details and amenities

### System Features
- **Dashboard** - Main control panel with system overview
- **Loading Screen** - Application startup interface
- **About Section** - Application information
- **Password Recovery** - Forget password functionality

## 🚀 Technology Stack

- **Language**: Java
- **GUI Framework**: Java Applet/Swing
- **Database**: MySQL
- **JDBC**: Database connectivity
- **IDE**: Any Java IDE (Eclipse, IntelliJ IDEA, NetBeans)
